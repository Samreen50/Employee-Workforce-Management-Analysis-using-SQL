# 📊 Employee Workforce Management & Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing employee workforce data using SQL. It demonstrates how to perform data retrieval, filtering, aggregation, and advanced analytical operations such as window functions and views.

The goal is to gain meaningful insights into employee distribution, salary structure, and departmental performance.

---

## 🎯 Objective

- Analyze employee data using SQL queries
- Understand workforce distribution across departments and locations
- Perform salary and experience-based analysis
- Apply MySQL concepts like CASE statements, aggregations, joins, views, and window functions

---

## 🗂️ Dataset Details

The dataset contains employee-related information with the following columns:

- employee_id – Unique identifier  
- full_name – Employee name  
- age – Age of employee  
- gender – Gender  
- department – Department name  
- salary – Salary of employee  
- experience_years – Work experience  
- location – City/location  

A total of 15 employee records are used for this analysis.

---

## 🛠️ Tools & Technologies

- MySQL

---

## 🔍 Key SQL Operations Performed

### 🧾 Basic Queries

- Retrieve all employee details  
- Filter employees by department (e.g., IT, Sales)  
- Find employees based on salary conditions  
- Sort and search using patterns  

### 📊 Aggregations

- Average salary per department  
- Total salary distribution  
- Minimum and maximum salary analysis  
- Department with highest employee count  

### 🎯 Conditional Logic

- Categorize employees (Junior / Mid / Senior) using CASE  
- Salary range categorization  

### 🔗 Joins & Views

- Self join to compare employee salaries  
- Created view: high_salary_employees  
- Querying views for further insights  

### 📈 Window Functions

- Ranking employees based on salary  
- Department-wise average salary comparison  
- Dense ranking based on experience  

---

## 📌 Sample Insights

- Departments with highest salary expenditure  
- Employee experience distribution  
- Salary comparison across departments  
- Identification of high-performing employees
